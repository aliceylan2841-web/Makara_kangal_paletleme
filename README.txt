PALET DÜZENİ – PWA (Acamay)
1) Bu klasörün tamamını HTTPS bir adrese yükleyin (Netlify Drop, GitHub Pages, Cloudflare Pages vb.).
2) pwabuilder.com → sitenizin adresini girin → Start.
3) Package for stores → Android (Google Play/APK) veya Windows / iOS paketini indirin.
Güncelleme yaptığınızda sw.js içindeki CACHE adını (palet-duzeni-v2 → v2) artırın.
